# เว็บเช็คชื่อคลาส Claude AI ✅

เว็บเช็คชื่อเข้าเรียนออนไลน์ ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์
ผู้เรียนแตะชื่อตัวเอง → เซ็นลายเซ็น → กด **ยืนยันเข้าเรียน (Approve)**
ระบบจะบันทึก **เวลา**, **สถานะ (ตรงเวลา / มาสาย X นาที)** และ **ลายเซ็น** ลง **Google Sheet** ทันที

## โครงสร้างไฟล์

```
Check-In/
├── index.html              ← หน้าเว็บทั้งหมด (HTML + CSS + JS ในไฟล์เดียว)
├── config.js               ← ใส่ URL ของ Google Apps Script ที่นี่
├── version.js              ← เลขเวอร์ชัน + รายการอัปเดตที่โชว์บนเว็บ
├── CHANGELOG.md            ← บันทึกการอัปเดตแต่ละเวอร์ชัน
├── apps-script/
│   ├── Code.gs             ← โค้ดหลังบ้าน วางใน Google Apps Script
│   └── appsscript.json     ← ค่าตั้งของ Apps Script (ใช้กับ clasp ได้)
├── sample/
│   └── รายชื่อตัวอย่าง.csv  ← รูปแบบไฟล์รายชื่อสำหรับนำเข้า
├── .gitignore              ← กันไฟล์รายชื่อจริงไม่ให้หลุดขึ้น GitHub
└── .nojekyll               ← ให้ GitHub Pages เสิร์ฟไฟล์ตรงๆ
```

## ขั้นที่ 1 — สร้าง Google Sheet และหลังบ้าน (Apps Script)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `เช็คชื่อคลาส Claude AI`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
4. ตั้งรหัสผู้สอน: **⚙️ Project Settings → Script Properties → Add script property** ชื่อ `ADMIN_KEY` ใส่รหัสที่ต้องการ (ไม่ต้องแก้ในโค้ด)
5. เลือกฟังก์ชัน **`setup`** ด้านบน แล้วกด **Run**
   ครั้งแรก Google จะขออนุญาต → เลือกบัญชี → *Advanced* → *Go to project* → *Allow*
   ระบบใช้แท็บ `Roster` · `Attendance` · `Data` · `Settings` ในชีต [ชีตระบบเช็คชื่อ](https://docs.google.com/spreadsheets/d/1klBN_8qHx4wM9WUr4dJSM4JxkRQB3RHkdcnX-bfNANY/edit) (แท็บไหนไม่มีจะสร้างให้)
6. กด **Deploy → New deployment** → คลิก ⚙️ เลือก **Web app**
   - **Execute as:** Me
   - **Who has access:** Anyone
7. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> 🔁 ถ้าแก้ `Code.gs` ภายหลัง ต้องไปที่ **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** ทุกครั้ง URL จะยังเป็นอันเดิม

## ขั้นที่ 2 — ใส่ URL ลงในเว็บ

เปิดไฟล์ [`config.js`](config.js) แล้ววาง URL ที่คัดลอกมา:

```js
window.ATTENDANCE_CONFIG = {
  SHEET_API_URL: 'https://script.google.com/macros/s/xxxxxxxxxxxx/exec'
};
```

## ขั้นที่ 3 — เอาขึ้น GitHub และเปิดเว็บด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `claude-ai-attendance`)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (กด **Add file → Upload files** แล้วลากทั้งโฟลเดอร์ หรือใช้คำสั่งด้านล่าง)
   ```bash
   git init
   git add .
   git commit -m "เว็บเช็คชื่อคลาส Claude AI"
   git branch -M main
   git remote add origin https://github.com/<ชื่อผู้ใช้>/claude-ai-attendance.git
   git push -u origin main
   ```
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
4. รอ 1–2 นาที จะได้ลิงก์ส่งให้ผู้เรียน — เว็บของคลาสนี้อยู่ที่ **https://imginhouse-cell.github.io/Check-In/**

> ใช้กับเซิร์ฟเวอร์อื่นก็ได้ แค่อัปโหลด `index.html`, `config.js` และ `version.js` ไว้โฟลเดอร์เดียวกัน

### 🏷️ การขึ้นเวอร์ชันใหม่
เลขเวอร์ชันโชว์บนส่วนหัวเว็บ (ป้าย `v1.2.0`) และท้ายเว็บ แตะเพื่อดูรายการอัปเดตและ commit ล่าสุดจาก GitHub
ทุกครั้งที่แก้เว็บแล้วจะปล่อยของใหม่:
1. เปิด `version.js` → เปลี่ยน `version` และ `date` แล้วเพิ่มรายการใหม่ไว้บนสุดของ `changelog`
   - แก้บั๊ก → `1.2.0 → 1.2.1` · เพิ่มความสามารถ → `1.2.1 → 1.3.0` · เปลี่ยนใหญ่ → `2.0.0`
2. เพิ่มหัวข้อเดียวกันใน `CHANGELOG.md`
3. commit แล้ว push ขึ้น `main` — GitHub Pages จะอัปเดตเว็บเองภายใน 1–2 นาที

## ขั้นที่ 4 — นำเข้ารายชื่อผู้เรียน

1. เปิดเว็บ → กด **🔒 โหมดผู้สอน** → ใส่รหัส `ADMIN_KEY`
2. กด **นำเข้ารายชื่อ** → เลือกไฟล์ **CSV หรือ Excel (.xlsx / .xls)**
   - หัวคอลัมน์ที่อ่านได้: `รหัส`, `ชื่อ-นามสกุล` (หรือ `ชื่อ` + `นามสกุล`), `ชื่อเล่น`, `บริษัท/หน่วยงาน`, `อีเมล`
   - ไฟล์จาก **Google Form** ที่มี `ชื่อ-นามสกุล 2`, `ชื่อ-นามสกุล 3` … จะแยกเป็นรายคนให้อัตโนมัติ
   - นำเข้าซ้ำได้ คนที่มีอยู่แล้วจะอัปเดต ไม่เพิ่มซ้ำ
3. หรือเพิ่ม/แก้รายชื่อตรงๆ ในแท็บ `Roster` ของ Google Sheet ก็ได้ (id ไม่ซ้ำกัน เช่น a23)

> ⚠️ **อย่าอัปโหลดไฟล์รายชื่อจริงขึ้น GitHub** เพราะเป็นข้อมูลส่วนบุคคล และ repo สาธารณะใครก็เปิดดูได้ — ให้นำเข้าผ่านหน้าเว็บแทน (`.gitignore` กันไฟล์ `.xlsx` และ `รายชื่อผู้เข้าเรียน*.csv` ไว้ให้แล้ว)

## ข้อมูลใน Google Sheet

| แท็บ | คอลัมน์ |
| --- | --- |
| `Data` | **timestamp** (วว/ดด/ปปปป ชช:นน), **name**, **note** (มา / สาย) — เพิ่มแถวทุกครั้งที่มีคนกดยืนยันเข้าเรียน |
| `Attendance` | วันที่, id, ชื่อ-นามสกุล, หน่วยงาน, เวลาเช็คอิน, สถานะ, สาย (นาที), บันทึกเมื่อ (ISO), ลิงก์ลายเซ็น, ลายเซ็น (ข้อมูลภาพ) |
| `Roster` | id, ชื่อ-นามสกุล, หน่วยงาน, ชื่อภาษาอังกฤษ — รายชื่อที่แสดงบนเว็บ |
| `Settings` | title, start (เวลาเริ่มเรียน), grace (นาทีที่ยังไม่นับสาย) |

- ลายเซ็นเก็บเป็นรหัสรูปภาพ (`data:image/...`) ดูรูปได้ในเว็บ: กดที่ชื่อคนที่เช็คชื่อแล้ว
- หน้าเว็บดึงข้อมูลใหม่ทุก 8 วินาที ทุกเครื่องจึงเห็นตรงกัน
- ผู้เรียนเช็คชื่อได้ **วันละครั้งต่อคน** (ระบบกันกดซ้ำ) ผู้สอนยกเลิกให้ได้

## สิทธิ์การใช้งาน

| ใคร | ทำอะไรได้ |
| --- | --- |
| ผู้เรียน (ทุกคนที่มีลิงก์) | ดูรายชื่อ, เช็คชื่อพร้อมเซ็นของวันนี้ |
| ผู้สอน (ใส่ `ADMIN_KEY`) | นำเข้า/ลบรายชื่อ, ยกเลิกการเช็คชื่อ, เช็คชื่อย้อนหลัง, ตั้งเวลาเริ่มเรียน, ส่งออก CSV |

## ถ้าไม่ใส่ URL ใน config.js

เว็บยังใช้งานได้ แต่ข้อมูลจะเก็บไว้ **เฉพาะในเบราว์เซอร์ของเครื่องนั้น** เหมาะกับการวางแท็บเล็ตเครื่องเดียวไว้หน้าห้อง

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
| --- | --- |
| ขึ้น “กำลังเชื่อมต่อฐานข้อมูล…” ค้าง | ตรวจว่า URL ใน `config.js` ลงท้ายด้วย `/exec` และตอน Deploy เลือก *Who has access: Anyone* |
| ใส่รหัสผู้สอนแล้วไม่ผ่าน | ตรวจ `ADMIN_KEY` ใน Project Settings › Script Properties |
| แก้โค้ดแล้วไม่เปลี่ยน | Apps Script ต้อง Deploy เวอร์ชันใหม่ / GitHub Pages รอ 1–2 นาทีแล้วรีเฟรช |
